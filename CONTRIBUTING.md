# Contributing

Thanks for considering a contribution to NeighborFit.

## Set up

Use Node.js 18 or later and npm 8 or later.

```bash
npm ci
npm run dev
```

## Before opening a pull request

Run the checks already provided by the project:

```bash
npm run lint
npm run type-check
npm run build
```

Describe the change and the user problem it addresses. For interface changes, include steps to reproduce and a screenshot when useful. Keep changes focused and do not add personal or confidential location data.
